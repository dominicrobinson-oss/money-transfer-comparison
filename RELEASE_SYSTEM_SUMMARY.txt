6-STEP RELEASE PROCESS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  CREATE RELEASE BRANCH
    git checkout -b release/v1.2.3

2️⃣  UPDATE VERSION
    Edit: package.json
    Change: "version": "0.1.0" → "version": "1.2.3"

3️⃣  RUN ALL GATES (MUST ALL PASS ✅)
    git status
    npx tsc --noEmit
    npm run test:smoke
    npm run test:deep
    npm run build

4️⃣  COMMIT & PUSH
    git add package.json
    git commit -m "chore: bump version to 1.2.3"
    git push origin release/v1.2.3

5️⃣  CREATE PR & WAIT FOR CI/CD
    ├─ Title: "Release: v1.2.3"
    ├─ Description: See RELEASE_CHECKLIST.md
    └─ Wait: All checks pass (green)

6️⃣  MERGE, TAG & CLEANUP
    git checkout main && git pull origin main
    git merge --no-ff release/v1.2.3
    git tag -a v1.2.3 -m "Release v1.2.3"
    git push origin main v1.2.3
    git push origin --delete release/v1.2.3

⏱️  Total time: 10-30 minutes
